## Quick Install

Download and run the installer directly from GitHub Releases:

1. Download **`LocalTelemetrySetup.exe`** from [**Latest GitHub Releases**](https://github.com/Nicconike/LocalTelemetry/releases/latest).
2. Run the installer and follow the setup wizard instructions. LocalTelemetry starts automatically.

```powershell
scoop bucket add localtelemetry https://github.com/Nicconike/LocalTelemetry

```

## Why LocalTelemetry?

Vendor software suites (such as NZXT CAM, Corsair iCUE, and ASUS Armoury Crate) consume hundreds of megabytes of RAM just to show system temperatures. Windows 11 also removed support for legacy taskbar deskbands.

LocalTelemetry brings hardware monitoring back where it belongs: lightweight, native, and completely offline.

### Feature Comparison

| Feature | LocalTelemetry | Vendor Suites (iCUE / CAM) | Legacy Monitors |
| :--- | :---: | :---: | :---: |
| **Native Win 11 Taskbar Integration** | Embedded | Floating overlay only | Broken on Windows 11 |
| **Memory Footprint** | **~45–60 MB (Taskbar)** / ~180 MB with Settings (WebView2) | 400–900 MB (Electron) | ~20–30 MB |
| **Direct Register Sensors (MSR / SMN)** | PawnIO Kernel Driver | Proprietary / Slow | Basic WMI only |
| **Privacy & Offline Operation** | **100% Offline (Zero tracking)** | Cloud telemetry & analytics | Local |
| **Settings Technology** | **Svelte 5 UI** | Heavy Web Wrapper | Win32 / MFC |
| **Game-Safe Alerts** | Focus-safe background toasts | Minimizes full-screen games | None |

---

## Key Features

- **Native Taskbar Overlay**: Embeds live metrics next to your clock. Automatically supports both centered and left-aligned Windows 11 taskbars.
- **Overlay Layout Presets**: Switch instantly between curated presets (Default, Compact, Gaming, Full Telemetry) or create custom arrangements with drag-and-drop ordering, preset sorting, live preview, and variant controls.
- **Deep Kernel Telemetry**: Direct CPU clocks, wattage, and thermals via Intel MSR and AMD SMN registers with ACPI fallback. Full support for NVIDIA (NVML), AMD (ADL), and Intel (IGCL) GPUs.
- **Real-Time Network Speed & History**: Track live upload and download speeds with local daily history logging, JSONL backup imports, and Windows network usage backfilling.
- **Adaptive OEM Brand Themes**: Detects installed hardware vendors (Intel, AMD, NVIDIA, Samsung, Corsair) and applies authentic manufacturer color palettes.
- **100% Offline & Private**: Zero telemetry collection, zero trackers, and zero cloud calls. All metrics stay strictly on your local PC.
- **Smart Game-Safe Alerts**: Anti-spike sustained breach filtering, 10°C thermal hysteresis, taskbar warning highlights, and non-intrusive focus-safe desktop toasts.

## Installation Options

### Option 1: Setup Wizard Installer (Recommended)

1. Download `LocalTelemetrySetup.exe` from [**GitHub Releases**](https://github.com/Nicconike/LocalTelemetry/releases).
2. Run the installer. Setup automatically verifies the .NET 10 Desktop Runtime and installs the required PawnIO kernel sensor driver.
3. LocalTelemetry starts immediately and runs quietly in your taskbar.

### Option 2: Scoop Package Manager

```powershell
scoop bucket add localtelemetry https://github.com/Nicconike/LocalTelemetry
scoop install localtelemetry
```

### Option 3: Portable ZIP

1. Ensure the required runtimes are installed:
   - [**Microsoft .NET 10 Desktop Runtime (x64)**](https://aka.ms/dotnet/10.0/windowsdesktop-runtime-win-x64.exe)
   - [**Microsoft Edge WebView2 Runtime (x64)**](https://go.microsoft.com/fwlink/p/?LinkId=2124703) *(pre-installed on Windows 11)*
2. Download `LocalTelemetry-win-x64.zip` from [**GitHub Releases**](https://github.com/Nicconike/LocalTelemetry/releases).
3. Extract and run `LocalTelemetry.exe` as Administrator.

<details>
<summary><strong>Verify Binary Signatures & SLSA Provenance</strong></summary>

<br />

Every release includes cryptographic hashes (`checksums.txt`), Sigstore Cosign signature bundles, and [SLSA](https://slsa.dev/) build attestations:

```powershell
# 1. Compare SHA-256 hashes against checksums.txt
Get-FileHash .\LocalTelemetrySetup.exe, .\LocalTelemetry-win-x64.zip -Algorithm SHA256

# 2. Verify keyless signatures with Cosign
cosign verify-blob --bundle .\LocalTelemetrySetup.exe.sigstore.json `
    --certificate-identity-regexp "https://github.com/Nicconike/LocalTelemetry/.*" `
    --certificate-oidc-issuer "https://token.actions.githubusercontent.com" `
    .\LocalTelemetrySetup.exe

# 3. Verify SLSA build provenance attestations
gh attestation verify .\LocalTelemetrySetup.exe --repo Nicconike/LocalTelemetry
gh attestation verify .\LocalTelemetry-win-x64.zip --repo Nicconike/LocalTelemetry
```

</details>
