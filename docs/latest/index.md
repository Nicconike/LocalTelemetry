    - icon: ":wifi-sync:"
      title: Gapless Network History
      details: Automatically imports past daily bandwidth from Windows system records back to your OS install date, alongside live speed metering.

    - icon: ":sun-snow:"
      title: Kernel Hardware Sensors

    - icon: ":swatch-book:"
      title: Hardware-Matched Metric Colors

    - icon: ":bell-ring:"

    - icon: ":shield-check:"
