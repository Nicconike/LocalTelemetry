## :layers: Project Responsibilities & Module Breakdown

### :layout-dashboard: Host Application & UI (LocalTelemetry.App)

Located in [`src/LocalTelemetry.App`](https://github.com/Nicconike/LocalTelemetry/tree/master/src/LocalTelemetry.App), this is the main execution target. Responsible for Win32 taskbar window reparenting (`TaskbarOverlay`), system tray management (`TrayIconManager`), threshold alerting (`AlertService`), update checking against GitHub Releases (`UpdateCheckService`), and hosting the Microsoft WebView2 control for settings management.

### :cpu: Hardware Engine & Telemetry (LocalTelemetry.Core)

Located in [`src/LocalTelemetry.Core`](https://github.com/Nicconike/LocalTelemetry/tree/master/src/LocalTelemetry.Core), this is the domain layer. Houses low-level hardware sensor readers, `PawnIO` kernel transport wrappers, WMI and Win32 storage IOCTL query interfaces (`DiskQuery`), hardware fingerprinting (`HardwareInventory`), lifecycle management (`HardwareLifecycleManager`), network bandwidth monitoring (`WindowsNetworkUsageProvider`), and configuration persistence (`AppSettings`).

### :bell: Toast Notification Helper (LocalTelemetry.Notifier)

Located in [`src/LocalTelemetry.Notifier`](https://github.com/Nicconike/LocalTelemetry/tree/master/src/LocalTelemetry.Notifier), this is a dedicated out-of-process toast notification executable. Runs in isolation to ensure hardware polling loops and full-screen games are never interrupted or de-focused when warnings trigger. Communicates exclusively over Windows Named Pipes (`LocalTelemetryNotifier`).

### :test-tube: Automated Testing Suites

Located in [`tests/`](https://github.com/Nicconike/LocalTelemetry/tree/master/tests), three distinct xUnit and Vitest test projects ensure regressions are prevented across hardware query logic, IPC messaging contracts, UI components, and settings serialization.

### :book-open: Documentation Portal

Located in [`docs/`](https://github.com/Nicconike/LocalTelemetry/tree/master/docs), the official VitePress documentation site extends standard markdown with automatic Lucide icon rendering, semantic alert callouts, and multi-version dropdown navigation. Includes a dedicated Reference & Specifications section for low-level contracts.

### :workflow: Continuous Integration & GitHub Automation

Located in [`.github/`](https://github.com/Nicconike/LocalTelemetry/tree/master/.github), automation workflows build, format, test, package, sign, and release LocalTelemetry in adherence with OpenSSF Scorecard supply-chain security standards.
